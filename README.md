Entry for the [make.fun bounty "The Battery's Last Text to Its Charger"](https://make.fun/c/u-alven-the-battery-s-last-text-to-its-charger-4278cfab).

## The entry

One line of plain text, the phone battery's final message to the charger it waited for all day. Down to 1%, it waited all day — only to find out the charger was in the kitchen the whole time. The punchline lands in the last words: it could have made it.

## How to run

Requires Node 22 or later. No dependencies to install.

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (creating `/output` if needed) and prints its character count. A built-in self-check refuses to write if the text is not a single line of 1–200 characters.
